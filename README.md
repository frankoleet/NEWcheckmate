# Круг — локальный шахматный турнир

Самостоятельное приложение React + TypeScript + Vite. Работает без регистрации, базы данных и сервера приложений. Интернет нужен только для установки зависимостей. Шрифты, иконки и остальной интерфейс доступны локально.

## Установка и запуск

Требуется Node.js 22.12+ (проверено на Node.js 24.13.1) и npm.

Откройте PowerShell в папке проекта:

```powershell
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5174/ . Порт закреплён: если он занят, Vite сообщит об ошибке, а не переключится на другой. Остановка — Ctrl+C в терминале с сервером. `npm start` запускает тот же сервер. Соседние проекты не используются.

## Проверки и сборка

```powershell
npm test
npm run build
npm run test:e2e
```

Vitest проверяет круговое вращение, отсутствие повторных пар, число игр и отдыха, подсчёт очков, общие места, исправление и удаление результата, валидацию и обмен JSON. Playwright проверяет составы на 15 и 20 игроков, три вкладки, результаты, подсказки, разворот таблицы, сохранение, импорт и экспорт, итоговые места, ошибки хранилища и мобильную ширину.

Для браузерных тестов нужен установленный Microsoft Edge (канал `msedge` в `playwright.config.ts`). Тесты используют отдельные временные профили, не затрагивая турнир в вашем браузере. Если сервер ещё не запущен, Playwright запускает его автоматически. Сборка находится в `dist/`.

## Использование

1. Введите название и список участников: одно имя на строку. Изменить или удалить игрока можно, отредактировав соответствующую строку до создания расписания. Пустые строки игнорируются; совпадающие имена, включая различия только в регистре, отклоняются. Добавьте фамилию или номер. Поддерживается от 2 до 128 игроков.
2. Нажмите «Создать турнир».
3. Во вкладке «Матчи» выберите тур и нажмите на встречу. Укажите победу первого, ничью или победу второго. Результат можно исправить или очистить в любом туре.
4. «Рейтинг» показывает очки и общие места; «Все встречи» — попарную таблицу. Нажатие на её ячейку также открывает результат. Фильтр игрока показывает статистику и оставшиеся встречи.
5. Используйте «Сохранить файл» для резервной копии. Загрузка проверяется до замены; замена турнира требует подтверждения и предлагает скачать текущий.

Победа — 1, ничья — 0,5, поражение — 0. Участники с одинаковыми очками делят место (например, 1, 1, 3). Ни алфавит, ни порядок добавления не определяют победителя. При нечётном составе каждый отдыхает один тур без очков и без сыгранного матча. Цвет фигур обозначает первого и второго игрока; дополнительная оптимизация баланса цветов не заявляется.

## Хранение

Текущий турнир: `krug-round-robin-v1`; черновик: `krug-new-tournament-draft-v1`; тема: `krug-theme`. Сохранения совместимы с исходным незавершённым вариантом этого проекта. Исходные файлы `app.js`, `core.js` и `server.mjs` сохранены, но новый проект их не загружает.

Данные привязаны к браузеру и адресу. Используйте один и тот же адрес `127.0.0.1:5174`, чтобы видеть прежнее сохранение. Очистка данных браузера удаляет сохранения, поэтому скачивайте JSON. При ошибке записи приложение показывает, что изменения не сохранены, и позволяет скачать файл. Повреждённый импорт не изменяет текущий турнир.

Сайт не опубликован в интернете; сервер слушает только локальный адрес.
